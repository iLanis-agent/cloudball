# Cloudball 1.0 TEST
Native Java/Canvas Android 8+ Dosun-Fuwari balloon and iron-ball support puzzle.

Place exactly one white balloon and one dark iron ball in each outlined room. Balloons need the top edge, a blocked X cell or another balloon immediately above. Iron balls need the bottom edge, a blocked X cell or another iron ball immediately below. Room borders do not support a piece. Tap an open tile to cycle empty, balloon, iron, empty. Twelve unique 4x4 layouts have twelve distinct solutions, each with a balloon stack crossing a room border.

Saved float palette and room labels, GG007 icon/menu/site/privacy, unlimited undo/reset. Offline, no ads, analytics, requested permissions or account. Settings and completion marks stay on device. External studio link opens browser.

Independent Java stack-walk/set oracle checks all ordered balloon/iron position pairs in every room combination plus 50000 random 32-bit masks per board against production local support checks, proving one solution each. Bounds, fixed blocks, three-state cycling, solve, undo and replay pass. Adapter menu, settings, privacy, tile taps, next, levels and persistence pass. Actual drawing-code pixels inspected, not phone screenshots. Phone runtime, performance and browser handoff QA incomplete. Signed TEST only, not final or Play published.
